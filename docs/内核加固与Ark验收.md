## 有限真实调用

实际使用用户指定的工程外新版火山文件。脚本为 `verification/ark_live_check.py`，全脚本上限八次模型、四次专业查询，每次模型请求最多输出 1500 tokens，无自动重试。

| 案例 | 实际模型请求 | 实际专业查询 | 结果 |
|---|---:|---:|---|
| 本地演示测评 → 用户研究 → 计算 → 建议 | 4 | 0 | `completed`，生成账本 |
| 人格与工作绩效研究 → 读取候选字段 → 条件 → 决策提交 | 4 | 1 | `completed`，生成账本 |
| 合计 | **8** | **1** | 两例完成，无本次失败请求 |

供应商回传总用量：输入 **36,334**、输出 **4,257**、合计 **40,591 tokens**，各请求输出未超过 1500。专业查询实际返回 `academic_search` 类型和 **49 条候选**，建议只采用已读取的字段。候选数量不表示每条相关或可靠。专业查询计数指业务查询尝试，不把 MCP 初始化、发现等协议消息计成额外资料查询。

具体每次调用状态、模型报告的缓存输入/推理 token 数字和本次案例 ID 保存在 Git 忽略的 `runtime/ark_verification/report.json`。没有实际 AFP 扣费返回，不能把 token 或请求数换算成已确认扣费。

模型声明的 256000 tokens 上下文和 32000 tokens 输出由用户指定并与[火山官方示例](https://docs.volcengine.com/docs/ark/agent-plan-enterprise-opencode?lang=zh)一致；本次未做满窗口或满输出测试。最终租约竞态修复和细分统计落盘经离线验证，没有为了重复检查再次消耗真实调用预算。
